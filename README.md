# Proyecto Web ALLSHOES - AE6.1

Este repositorio contiene la materialización web de la visión gráfica para la marca **ALLSHOES**. El proyecto consiste en una presentación interactiva de cinco diapositivas convertidas en páginas web funcionales, utilizando exclusivamente **HTML5** y **CSS3**.


[https://joanmofu.github.io/proyecto-web-asir-1/](https://joanmofu.github.io/proyecto-web-asir-1/)

---

## 📂 Estructura del Proyecto

El código se ha organizado de forma lógica y profesional para garantizar la mantenibilidad. Siguiendo los requisitos obligatorios, todos los identificadores y clases se han nombrado en **español**.

* **`index.html`**: Diapositiva 1 - Página de Inicio.
* **`html/`**: Directorio que contiene las diapositivas restantes:
* `sobre-nosotros.html`: Diapositiva 2 - Información de la empresa.
* `cursos.html`: Diapositiva 3 - Oferta formativa.
* `tienda.html`: Diapositiva 4 - Catálogo de productos.
* `contacto.html`: Diapositiva 5 - Formulario y redes sociales.


* **`css/`**: Contiene las hojas de estilo segmentadas por función:
* `generico.css`: Estilos base y normalización.
* `header.css`: Estilos de la cabecera global.
* `index.css`, `contacto.css`, etc.: Estilos específicos para cada sección.


* **`recurses/`**: Carpeta de recursos que incluye logotipos, imágenes de artículos y de cursos.

---

## 🕹️ Cómo navegar por las diapositivas

La navegación es intuitiva y está presente en todas las páginas a través de la **cabecera principal**:

1. **Menú de Navegación**: Utilice los enlaces en la parte superior derecha para desplazarse entre las secciones: **Inicio, Sobre Nosotros, Cursos, Tienda y Contacto**.
2. **Logotipo**: Al hacer clic en el logotipo de la esquina superior izquierda, el usuario regresará siempre a la página de inicio.
3. **Botones de Acción**: La página de inicio incluye un botón de "COMPRA AHORA" que redirige directamente a la tienda para mejorar la conversión.

## 🛠️ Información Relevante para el Cliente

Como desarrolladores, hemos priorizado los siguientes aspectos técnicos para dar vida a los mockups:

* **Estructura Semántica**: Se han utilizado etiquetas lógicas de HTML para que la web sea accesible y esté bien estructurada.
* **Interactividad y Efectos**: Se han implementado efectos de **hover** (al pasar el ratón) en botones, enlaces y tarjetas de productos, así como transiciones suaves para mejorar la experiencia del usuario.
* **Formulario de Contacto**: Incluye validación de datos en tiempo real mediante CSS. Los campos cambian de color (verde/rojo) según si la información introducida es válida o no, asegurando que el cliente reciba mensajes correctamente formateados.
* **Fidelidad al Diseño**: Se ha respetado rigurosamente la disposición de elementos, tipografía y colores proporcionados en los mockups originales.
